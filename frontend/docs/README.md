## Documentation conventions

- Use sentence-case headings and fenced `bash` blocks for commands.
- Use repository-relative Markdown links and the shared terms **scenario**, **class**, **simulation
  run**, **weekly turn**, **professor**, and **student**.
- Keep API status values in code formatting and show human-readable status labels in the UI.
- Add **Related documentation** links whenever a frontend contract depends on a backend contract.
