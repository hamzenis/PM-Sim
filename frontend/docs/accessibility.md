# Accessibility

Use semantic landmarks and controls, one descriptive page heading, programmatic labels, visible focus,
and keyboard-operable interactions. Loading changes and request failures must be perceivable without
colour alone. Status badges need text labels, and destructive confirmations need a clear action name
and safe focus order.

Check desktop and mobile layouts for horizontal overflow and retain 44-pixel action targets. Run the
component accessibility coverage and the Playwright role-and-route audit when changing a workflow;
also navigate the changed path using only a keyboard.
