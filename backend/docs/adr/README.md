# Architecture decision records

Architecture decision records (ADRs) capture durable decisions and their consequences. They are
append-only: supersede an accepted decision with a new numbered ADR rather than rewriting its
history.

| Status | Decision |

| Accepted | [ADR 0002: Authored-content persistence and legacy idempotency](0002-content-persistence-idempotency.md) |

Use the status labels **Proposed**, **Accepted**, **Superseded**, or **Rejected** consistently.
